# Portfolio — Samuel Lepinay

Portfolio personnel d'un étudiant en Bachelor Systèmes & Cybersécurité (ESGI Toulouse), en recherche d'alternance.

**En ligne :** https://porte-folio-sand.vercel.app

## Stack

- Next.js 16 (App Router) · React 19 · TypeScript
- Tailwind CSS 4 (palette « graphite & cuivre » définie dans `src/app/globals.css`)
- Déploiement sur Vercel

## Modifier le contenu

Tout le contenu (textes, projets, parcours, liens) est centralisé dans `src/data/site.ts`.
Le CV se dépose dans `public/cv.pdf`.

## Lancer en local

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.
